# SQL-University-Course-Management-System

📌 Project Overview
The University Course Management System is a SQL-based database project developed utilizing PostgreSQL. This initiative showcases comprehensive database design, data manipulation, and data retrieval methodologies within a university database schema encompassing students, courses, instructors, enrollments, and departments.
The primary objective is to gain practical experience with SQL concepts, spanning from foundational CRUD operations to advanced queries incorporating joins, subqueries, aggregate functions, date manipulation, and window functions.

🎯 Project Objectives
- Design and manage a relational database utilizing PostgreSQL.
- Execute CRUD operations: Create, Read, Update, and Delete.
- Retrieve and filter records employing SELECT, WHERE, ORDER BY, and LIMIT clauses.
- Analyze data through aggregate functions combined with GROUP BY.
- Apply HAVING clauses to filter aggregated results.
- Extract related information using INNER JOIN and LEFT JOIN.
- Address analytical challenges leveraging subqueries.
- Utilize date functions and perform string manipulation.
- Compute running totals implementing window functions.
- Implement conditional logic utilizing CASE statements.
